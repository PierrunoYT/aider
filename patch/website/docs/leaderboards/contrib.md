# Contributing results

Contributions of benchmark results are welcome!
See the
[benchmark README](https://github.com/PierrunoYT/patch/blob/main/benchmark/README.md)
for information on running patch's code editing benchmarks.
Submit results by opening a PR with edits to the
[benchmark results data files](https://github.com/PierrunoYT/patch/blob/main/patch/website/_data/).
