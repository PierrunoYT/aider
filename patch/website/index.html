AI pair programming in your terminal

Patch lets you pair program with LLMs to start a new project or build on your existing codebase.

Get Started Documentation

Features

Cloud and local LLMs

Patch works best with Claude 3.7 Sonnet, DeepSeek R1 & Chat V3, OpenAI o1, o3-mini & GPT-4o, but can connect to almost any LLM, including local models.

Maps your codebase

Patch makes a map of your entire codebase, which helps it work well in larger projects.

100+ code languages

Patch works with most popular programming languages: python, javascript, rust, ruby, go, cpp, php, html, css, and dozens more.

Git integration

Patch automatically commits changes with sensible commit messages. Use familiar git tools to easily diff, manage and undo AI changes.

In your IDE

Use patch from within your favorite IDE or editor. Ask for changes by adding comments to your code and patch will get to work.

Images & web pages

Add images and web pages to the chat to provide visual context, screenshots, reference docs, etc.

Voice-to-code

Speak with patch about your code! Request new features, test cases or bug fixes using your voice and let patch implement the changes.

Linting & testing

Automatically lint and test your code every time patch makes changes. Patch can fix problems detected by your linters and test suites.

Copy/paste to web chat

Patch works best with LLM APIs, but it can also work an LLM via its web chat interface. Patch streamlines copy/pasting code back and forth with a browser.

Getting Started

python -m pip install patch-code

# Change directory into your codebase
cd /to/your/project

# DeepSeek
patch --model deepseek --api-key deepseek=<key>

# Claude 3.7 Sonnet
patch --model sonnet --api-key anthropic=<key>

# o3-mini
patch --model o3-mini --api-key openai=<key>
